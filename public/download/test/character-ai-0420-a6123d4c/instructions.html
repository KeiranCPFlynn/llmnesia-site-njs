What this test does

The new Recover up to 3 archives button tries a small batch of pending archived chats. Before the test starts, it asks your permission to unarchive those chats if needed. If Character.AI refuses to read an archived chat, the test unarchives it in your Character.AI account and then tries importing it again.

Recovered chats stay unarchived, including if importing or saving fails. They may appear in your Character.AI recent chats. This test does not rearchive or delete them. Ordinary imports do not unarchive chats.

We have checked the unarchive request with our own disposable test chat, and tested the recovery flow with synthetic cases. We have not reproduced your exact older archives, so this test may still be unable to retrieve some chats, especially those belonging to unavailable bots.

Update your existing test copy

  1. Use the same temporary Chrome profile and private LLMnesia copy you used for the earlier test. Do not remove the extension, clear its data or make another profile.
  2. Finish any running import and close the Character.AI tabs in that temporary profile.
  3. Download the new ZIP above and extract it to a temporary location.
  4. Copy the contents of the newly extracted folder into the original folder you selected with Load unpacked, replacing files when asked. Keep that original folder at the same path. It is the folder containing manifest.json.
  5. Open chrome://extensions in the temporary profile and click the reload button on the existing LLMnesia test entry. Do not remove and reinstall it. The entry should now say LLMnesia Character.AI Test 3, version 0.4.21.3. Your saved chats should still be there.
  6. Open character.ai and sign in to the same Character.AI account if needed. Leave Vault disconnected.

Try three archives

  1. With Character.AI open, open the LLMnesia popup and choose Recover up to 3 archives. You do not need to repeat the full import or set a limit.
  2. Read the confirmation. Continue only if you are happy for up to three pending archived chats to become unarchived in your Character.AI account. Cancel leaves them unchanged.
  3. Keep the Character.AI tab open until the test finishes. You do not need to locate each bot or share any chat links or text.
  4. The technical results are sent automatically. Please wait for Keiran to review them before running another recovery batch.

This test does not schedule another recovery batch automatically. Keep the test profile, extracted folder and chats it has saved while we review the results.

Installing this private build for the first time
  1. Keep your usual Chrome profile and LLMnesia installation as they are. Add a separate temporary Chrome profile; you can continue without a Google account.
  2. Download and extract the ZIP to a folder you can keep in place.
  3. In the temporary profile, open chrome://extensions, switch on Developer mode, choose Load unpacked and select the folder containing manifest.json.
  4. Sign in to Character.AI in that profile and complete LLMnesia setup. Leave Vault disconnected. Run one ordinary import first, then follow the three-archive test above.

A new profile has a separate index. Its saved chats do not automatically appear in your usual installation.

About diagnostics

This private build automatically shares Character.AI import diagnostics with LLMnesia through PostHog. This recovery build starts a fresh 24-hour reporting window with your first import or recovery attempt. This applies only to this private test build.

The reports include discovery and queue counts, archive state, request timings and status codes, recognised error categories, extracted message counts, save results, unarchive request outcomes, and the final import outcome. A random test identifier lets us connect the results from your attempts.

Chat text, titles, chat and character IDs, URLs, passwords, access tokens, and raw responses are excluded. No Vault connection is needed. If an upload fails, a small report queue is kept locally for retry within the same 24-hour window.

Your usual Chrome profile and extension can continue to be used normally. Keep the extracted folder in place while the test copy is installed.
