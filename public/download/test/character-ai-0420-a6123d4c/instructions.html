# LLMnesia private Character.AI test build

Prepared 25 October 2026. This is a private test, not a public release.

File: llmnesia-0.4.20-character-ai-private-2b824dc1.zip
Version: 0.4.20. Diagnostic build identifier: 2b824dc1.

This build lets the import continue past chats Character.AI refuses to provide. It also stops automatic retries after an access refusal. It cannot promise recovery of a refused chat. Unavailable bots could be related, but that has not been confirmed.

## Install without disturbing your existing saved chats

1. Keep your current LLMnesia installation and Chrome profile as they are. Do not uninstall it or clear its data.
2. In Chrome, use the profile button to add a separate temporary profile. You can continue without a Google account. This keeps the test separate from your usual saved chats.
3. Extract the ZIP to a folder you can keep in place while testing.
4. In the temporary Chrome profile, open chrome://extensions and switch on Developer mode. Choose Load unpacked and select the extracted folder containing manifest.json.
5. Open character.ai in that same temporary profile and sign in to the same Character.AI account as usual. Complete LLMnesia's setup if it opens. You do not need to connect Vault for this test.

The test copy has a separate, initially empty search index. It may import chats you already saved in your usual installation. That is expected for this separate copy, and does not mean the existing saved chats have been removed or overwritten. Keep any chats saved by the test copy until we have agreed how to retain them; they will not automatically appear in the store copy.

## Try the import

1. With character.ai open, open the LLMnesia popup. Set the import limit to 10 and choose Import chats.
2. Leave the Character.AI tab open until the run finishes. There is no need to locate, open, or unarchive the unavailable bots.
3. Please tell us the number saved and the exact final status message, especially whether it passes the point where it previously stopped after three failures.
4. If it still gets stuck, send a fresh diagnostic report from the test copy. You do not need to include chat text, passwords, or access tokens.

If some chats are refused, the build should say automatic retries are paused. A manual import starts another deliberate attempt. There is no need to repeatedly retry refused chats for this test.

Your usual Chrome profile and extension can continue to be used normally. Keep the extracted folder in place while the test copy is installed.
