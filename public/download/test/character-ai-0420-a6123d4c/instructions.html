Character.AI private import test

Thanks for helping us test this change. This is an unlisted test build for Chrome, separate from the public store version.

Download private test ZIP (20 MB)

Keep your existing LLMnesia installation. Use a separate temporary Chrome profile for this test so your saved chats stay intact.

What this build changes

The import can continue past chats Character.AI refuses to provide and save the others. It also stops automatic retries after an access refusal. It may still be unable to retrieve the refused chats. Unavailable bots could be related, but that has not been confirmed.

Set up the test copy

  1. Keep your usual Chrome profile and LLMnesia installation as they are. Do not uninstall the extension or clear its data.
  2. In Chrome, use the profile button to add a separate temporary profile. You can continue without a Google account.
  3. Download the ZIP above and extract it to a folder you can keep in place while testing.
  4. In the temporary profile, open chrome://extensions and switch on Developer mode. Choose Load unpacked and select the extracted folder containing manifest.json.
  5. Open character.ai in that temporary profile and sign in to your usual Character.AI account. Complete LLMnesia’s setup if it opens. Leave Vault disconnected for this test.

The test copy starts with a separate, empty search index, so it may import chats you already saved in your usual installation. That is expected. Your original saved chats stay in the original profile.

Keep any chats saved by the test copy until we have agreed how to retain them. They will not automatically appear in the store copy.

Try the import

  1. With Character.AI open, open the LLMnesia popup. Set the import limit to 10 and choose Import chats.
  2. Leave the Character.AI tab open until the run finishes. There is no need to locate, open, or unarchive the unavailable bots.
  3. Reply to Keiran with the number saved and the final status message. In particular, let us know whether it passes the point where it previously stopped after three failures.
  4. If it still gets stuck, send a fresh diagnostic report from the test copy. You do not need to include chat text, passwords, or access tokens.

If some chats are refused, the build should say automatic retries are paused. A manual import starts another deliberate attempt. There is no need to repeatedly retry refused chats for this test.

About diagnostics

Automatic diagnostic reporting is disabled by default for this unpacked test copy. We currently need your reply or a diagnostic report to understand how this test went.

Your usual Chrome profile and extension can continue to be used normally. Keep the extracted folder in place while the test copy is installed.
