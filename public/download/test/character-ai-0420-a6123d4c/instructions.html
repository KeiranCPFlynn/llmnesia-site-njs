Character.AI Test 5: full recovery

This private Chrome copy works through all the chats Character.AI makes available in one run, including archives. It replaces the small three-chat test.

Download Test 5 (20 MB)

Keep your older test copies and their saved chats. Switch those copies off, then load Test 5 from a new folder. No copying or replacing old files is needed.

Before you start

This run may unarchive hundreds of chats in your Character.AI account. It asks for confirmation before starting. It first tries reading a chat; if an archived chat is refused, it can unarchive it and try reading it again.

Restored chats stay unarchived, even if importing or saving fails. They may appear in Character.AI’s recent chats. This copy does not rearchive or delete them. Please continue only if you are happy with that.

Load the new copy

  1. Download the ZIP above and extract it to a new folder you can keep in place. Leave your earlier test folders alone.
  2. In the same Chrome test profile as before, let any current import finish and close its Character.AI tabs. Open chrome://extensions and use the toggles to switch off the older LLMnesia test entries. Do not remove them or clear their data.
  3. Click Load unpacked and select the new folder containing manifest.json. If needed, switch on Developer mode to see Load unpacked. The new entry should say LLMnesia Character.AI Test 5, version 0.4.21.5.

Close any LLMnesia welcome tab without starting an ordinary import. Leave Vault disconnected. Test 5 starts with its own empty search index; your earlier saved chats remain with the older copies.

Run recovery once

  1. Open character.ai in that test profile and sign in to your usual account if needed.
  2. Open the popup for LLMnesia Character.AI Test 5 and click Recover available chats once. Read the confirmation before continuing. You do not need to set a limit or find individual bots.
  3. Keep Chrome and the Character.AI tab open until the run finishes. A large history can take a while. You can pause or stop from the popup if needed.

The run saves readable active chats and archives, waits briefly for restored messages, and continues past unavailable chats. Chats already saved in Test 5 are left alone. Some messages may remain unavailable even after Character.AI accepts an unarchive request.

When it ends, the popup shows saved, failed, skipped and any unattempted counts. The technical results are sent automatically, so there is no need to send logs, chat links or message text. A finished pass does not guarantee that Character.AI provided every historical message.

If sign-in expires, the tab closes or Character.AI imposes a persistent rate limit, the saved chats remain in Test 5. Recovery will not restart automatically. Keep the copies and folders while Keiran reviews the results.

About automatic reporting

This private copy sends technical Character.AI import diagnostics to LLMnesia through PostHog for 24 hours after its first import or recovery attempt. The new copy has its own reporting window.

Reports include discovery and queue counts, archive state, timings, status codes, recognised error categories, extracted message counts, acknowledged save results, unarchive outcomes, read retries and the final saved/failed totals. A random test identifier connects the technical events from the same attempt. Detailed reporting is bounded; final aggregate counts are retained even if that detailed-event budget is reached.

Chat text, titles, chat and character IDs, URLs, passwords, access tokens and raw responses are excluded. No Vault connection is needed. Failed uploads retain a small local retry queue within the same reporting window.

Return to the chats saved by an older copy

Close Character.AI tabs, open chrome://extensions, switch Test 5 off, then switch on the older copy whose saved chats you want to search. Reopen LLMnesia search. Keep only one test copy switched on at a time. The separate indexes do not merge automatically.
