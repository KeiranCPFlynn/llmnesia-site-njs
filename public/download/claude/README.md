# LLMnesia for Claude Desktop

`llmnesia.mcpb` is the read-only Claude Desktop extension distributed from the
stable URL:

https://www.llmnesia.com/download/claude/llmnesia.mcpb

The binary must be rebuilt from the matching LLMnesia release commit and
replaced for each release. The response is revalidated rather than cached
indefinitely so this permanent URL can continue pointing at the current tested
file.
