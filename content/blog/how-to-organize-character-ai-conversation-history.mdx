**Organise around the character, the separate storyline, and a date you can recognise.** Keep a searchable copy of important conversations and a separate backup of anything irreplaceable.

## Current status, checked October 22, 2026

Character.AI announced a Chapter 11 sale process on October 12. It says the service remains available while it seeks a buyer, and may close if no suitable bid allows continued operation. This is not a confirmed shutdown date. See [Character.AI's announcement](https://blog.character.ai/an-update-on-character-ai/). Keep copies of conversations that matter to you, and check that you can read them independently of the site.

## Keep a simple story index

Use a local document or notes app with one entry per storyline. Include the character name, a descriptive story title, approximate dates and a link where available. Add a memorable phrase so you can find the corresponding saved transcript later. A link alone will not preserve a chat if the original disappears.

## Separate sessions with the same character

Several conversations with one character can represent different stories. Give your own saved files distinct names rather than overwriting one file for every character. Keep original downloads alongside readable copies, and check that timestamps supplied by an export are real conversation dates rather than export dates.

## Search the text you have captured

LLMnesia searches locally saved conversations by keyword. Filter to Character.AI and use a specific plot detail or phrase. Version 0.4.19 includes history discovery for older sessions with a character and archived chats, subject to what Character.AI returns. Check saved counts and important chats after importing.

LLMnesia saves and searches captured text locally. Optional Vault sync uploads encrypted copies when you enable it. Neither capture nor import can recover messages the source no longer provides. A search index is not a substitute for a separate backup: removing an extension or clearing its storage can remove local copies.

## Keep independent backups

Request the official export, which may take 3 to 4 weeks. Download it within 7 days of the email. Check the files rather than assuming every chat is included. For an immediate readable copy, copy loaded text into a document, or try printing to PDF and inspect the pages.

Keep your own character definitions separately if you created them. Importing a transcript elsewhere does not preserve the original model's personality or promise identical replies.
