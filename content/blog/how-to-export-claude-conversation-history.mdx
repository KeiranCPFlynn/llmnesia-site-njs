Claude offers an account export for backing up accessible history. A dedicated exporter can also save one conversation as a readable document. Choose according to whether you need an archive, a shareable transcript or context for another assistant.

## Request your Claude export

1. Open Claude on the web or in Claude Desktop.
2. Go to **Settings**, then **Privacy**.
3. Select **Export data**.
4. Open the emailed link while signed in to the account that requested it.
5. Download and inspect the export before depending on it.

Anthropic says the link expires 24 hours after delivery. Individual Free, Pro and Max users can export. Team and Enterprise members need an owner to enable member exports; Primary Owners use the organisation export route. See the [official export instructions](https://support.claude.com/en/articles/9450526-export-your-claude-data) if the control is missing. Mobile apps do not initiate the export.

The same documentation says exported data cannot be imported into another personal Claude account. Attaching a transcript for reference is a separate workflow.

## Check the archive before converting it

Keep an untouched copy of the download. Inspect the conversation data in an extracted copy and compare a few threads with the originals, including their final messages. Verify any artifacts, attachments and project context individually. A transcript containing a reference to a file does not establish that the file itself is preserved.

For raw JSON, use a text editor to find a distinctive phrase. For regular browsing, a converter that produces one readable file per conversation can be more convenient. Preserve speaker labels and source details when available, and check the converted output before deleting or reorganising anything.

## Export a single conversation

Several tools have similar Claude Exporter names. These are distinct products, so follow the exact links rather than assuming they share features or privacy policies.

| Tool | Documented purpose | What to check |
|---|---|---|
| [AI Chat Exporter](https://www.ai-chat-exporter.net/en) | Save selected Claude chats in several formats, including PDF and Markdown | Its FAQ says PDFs use temporary server processing; other formats run in the browser |
| [AI Toolbox](https://www.ai-toolbox.co/) | Search, organise and export across four AI websites | Single-chat TXT is free; additional formats require Premium |
| [YourAIScroll](https://chromewebstore.google.com/detail/youraiscroll-ai-chat-hist/nhipdhjmedoeicanabmcmihlncjcanfe) | Multi-platform exports, with artifact and citation support advertised | Check the supported platform, format and complex-content output |
| [Save my Chatbot](https://save.hugocollin.com/) | Download threads from supported sites, including Claude | Confirm current support and inspect a representative transcript |

These descriptions reflect public documentation checked on 18 October 2026. They are options to evaluate, not a hands-on ranking or a guarantee of complete exports.

## Keep history searchable with LLMnesia

LLMnesia's current Claude importer reads older chats through your signed-in browser session. It does not currently import Claude's downloaded export ZIP. Keep the ZIP as an independent backup and use **Import older chats** for the searchable local archive.

Once the import finishes, search for a known phrase and check the saved conversation. Supported new chats can then be captured as you work. The [free local MCP connection](/mcp) lets compatible desktop assistants consult those captured conversations and return source links. Optional [Vault](/vault) adds paid end-to-end encrypted sync and backup.

## Reuse the transcript in another assistant

Exported files can supply useful context when the destination supports their format. Start with the relevant project threads, state which decisions are current and ask the assistant to identify unresolved questions before continuing.

File and context limits still apply, and uploading a transcript does not restore a native thread or transfer all account memory.
