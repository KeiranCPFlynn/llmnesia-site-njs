**To search ChatGPT, Claude, Gemini and Perplexity history together, save the conversations to one local index.** Install LLMnesia in Chrome or Edge, capture or import the chats you want to keep, then search for a word or phrase after keyword indexing finishes. One query searches the titles and messages saved from each assistant.

## Try one search across three assistants

This example uses three sample chats. To reproduce it, start a chat on each site and include the words `launch checklist` in a message body, while letting each conversation have a different title.

| Assistant | Sample chat title | Sample message text |
| --- | --- | --- |
| ChatGPT | Release dates | Add the release dates to the launch checklist. |
| Claude | Review owners | Assign a reviewer for each item on the launch checklist. |
| Gemini | Rollout risks | Put the rollback plan on the launch checklist. |

1. In the browser where LLMnesia is installed, open the three chats and confirm they have been captured. For older conversations, use the import controls and check which chats were saved.
2. Open LLMnesia search. With the platform filter set to show all platforms, enter `launch checklist` once.
3. After keyword indexing, look for all three titles. Open a result and check the matching message. The words are in the saved messages, so you can find the chats without knowing their titles.

If you know where a conversation happened, start with that assistant's own history. If you remember the subject and use several assistants, search the local copies together.

## What your local search can find

Search covers conversations successfully saved to the local index. Source permissions, expired sessions, and account or workspace restrictions can limit imports. If you expected an older chat, open it on the original service or check the import details, then try a distinctive phrase once its saved copy is indexed. A deleted chat is searchable only if you still have an indexed copy or can import an earlier backup.

The free extension stores and searches its index on your computer. You sign in to the original assistant to access its account history. [Vault](/vault) is optional paid encrypted backup and sync. For details on storage and analytics, see the [privacy policy](/privacy-policy).
