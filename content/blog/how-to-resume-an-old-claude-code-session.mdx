**Run `claude --resume` to choose a saved Claude Code session or `claude --continue` to reopen the most recent eligible session in your current directory.** If the session belongs to another project, press **Ctrl+A** in the picker. If you know its ID, run `claude --resume <session-id>`.

## The three built-in ways to resume

**`claude --continue` (or `-c`)** reopens the most recent eligible session in the current directory.

**`claude --resume` (or `-r`)** opens the session picker. Type to filter it, or pass a session ID to jump straight to a specific session.

**`/resume`** opens the picker from inside a running Claude Code session.

All three restore the session's context so Claude picks up with the history intact, rather than starting cold.

## Resume a session from another worktree or project

The picker initially shows sessions associated with the current worktree. Press **Ctrl+W** to include the repository's other worktrees or **Ctrl+A** to show all projects on the machine. When you pick a session from an unrelated project, Claude Code can copy a command that changes to that project and resumes the session.

If you pass an ID from a different directory, Claude Code searches the current project and its worktrees first, then looks for a unique match elsewhere. If an older build cannot find it, run the command from the original project directory. See [where Claude Code stores its transcript files](/blog/where-does-claude-code-store-history) to locate the ID.

## Resuming a session you can't place

If you remember a line from the conversation but cannot identify it in the picker, search the saved transcript files by content.

Two ways through it:

- **Search the files.** With the default location and ripgrep installed, run `rg -il --glob '*.jsonl' -- 'something you remember' ~/.claude/projects`. For a matching session transcript, use the filename without `.jsonl` as the ID.
- **Search your saved sessions with LLMnesia.** [LLMnesia for Claude Code](/claude-code) builds a local keyword index from the supported session files you import. Find a saved conversation by a phrase you remember and copy its resume command.

If you cannot place the session at all, work through the [methods for finding an old Claude Code conversation](/blog/how-to-find-an-old-claude-code-conversation) first, then come back and resume it.

## Keeping sessions easy to return to

These habits make a session easier to find later.

- **Use `--continue` for recent work** in the same project.
- **Keep projects in stable directories.** Moving or renaming a project directory means its future sessions land in a new folder, splitting your history.
- **Name or index sessions you expect to revisit.** A meaningful session name helps in the picker. A local index helps when you remember the conversation's contents.
