**Claude Code stores local session history under `~/.claude/projects/` by default.** Look inside the folder for the project you worked in. Its `.jsonl` files contain saved session transcripts. If you use `CLAUDE_CONFIG_DIR`, look in the `projects` folder under that directory instead.

## Find the session folder on your computer

| Where you ran Claude Code | Default local path |
|---|---|
| macOS | `/Users/<you>/.claude/projects/` |
| Linux or WSL | `~/.claude/projects/` in that environment |
| Native Windows | `%USERPROFILE%\.claude\projects\` in File Explorer |

On macOS, use **Go to Folder** in Finder and enter `~/.claude/projects`. In WSL, check the Linux home directory used by Claude Code. If you use separate configuration directories or run Claude Code on another machine, check the directory and machine you used for the original session.

Inside `projects`, subfolders are usually named from the working directory you opened Claude Code in. A session file is generally named with its session ID. You can open it in a text editor. Each line is a JSON object, and a file may contain tool output as well as what you and Claude said.

## Reopen a session without opening JSONL

From the project directory, run `claude --resume` to open the session picker. Use `/` to filter the list. Press **Ctrl+A** to show sessions from all projects on that machine. Selecting a session from an unrelated project can copy a command you run in your terminal. If you know the ID, run `claude --resume <session-id>`. Inside Claude Code, `/resume` opens the picker. For more options, see the [Claude Code session resume guide](/blog/how-to-resume-an-old-claude-code-session).

## Why a session file might be missing

- **Wrong folder or machine.** Check the original project, worktree, and configuration directory. A cloud session started in Claude Code on the web has its own history in that service.
- **Local cleanup.** Anthropic documents a 30-day default for local CLI transcript retention. The `cleanupPeriodDays` setting controls that period. Sessions started or most recently continued in Claude Desktop or Cowork are exempt by default.
- **Persistence disabled.** A print-mode run started with `--no-session-persistence` does not save a transcript. `CLAUDE_CODE_SKIP_PROMPT_HISTORY` can disable persistence in other modes.
- **Remote Control.** It runs Claude Code on your computer. While connected, Anthropic also stores a transcript on its servers so the remote view can stay in sync. Check the original computer for the local copy.

## Search or back up the files

If you remember a phrase but have forgotten the project, search the local transcript files. On macOS or Linux, with ripgrep installed:

```bash
rg -il --glob '*.jsonl' -- 'phrase you remember' "${CLAUDE_CONFIG_DIR:-$HOME/.claude}/projects"
```

This lists matching filenames. Matches can come from tool output as well as messages. To preserve the transcripts still on disk, copy the `projects` folder to a private backup. The files are plaintext and may contain sensitive code and prompts.

For repeat searches, [LLMnesia for Claude Code](/claude-code) can import the local session folder and index supported saved sessions alongside browser chats. Once indexing finishes, search by a phrase you remember and use the result to find the session or its resume command. If you are looking for a specific session right now, start with the [guide to finding an old Claude Code conversation](/blog/how-to-find-an-old-claude-code-conversation).
