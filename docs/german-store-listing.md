## Detailed description

Finde Antworten, die du bereits hattest. LLMnesia durchsucht deinen gespeicherten KI-Chatverlauf in ChatGPT, Claude, Gemini, DeepSeek, Kimi, Qwen und anderen unterstützten Tools.

Importiere deinen bestehenden Verlauf, durchsuche indizierte Unterhaltungen, filtere Ergebnisse und öffne die passende Nachricht. Gespeicherte Kopien können offline gelesen und exportiert werden. Unterhaltungen, die gelöscht wurden, bevor LLMnesia sie gespeichert hat, können nicht wiederhergestellt werden.

Die kostenlose lokale Suche speichert deine Gesprächsinhalte und den Suchindex in deinem Browser auf diesem Gerät. Es ist kein Konto erforderlich. Der optionale kostenpflichtige Vault bietet eine Ende-zu-Ende-verschlüsselte Sicherung, Synchronisierung und eine Web-App. Die eingeschränkte Produktanalyse umfasst weder Gesprächsinhalte noch Suchanfragen.

Sprache: Eine deutsche Einführung und Installationsanleitung findest du unter https://www.llmnesia.com/de. Die Benutzeroberfläche der Erweiterung, Vault und die Zahlungsseiten sind derzeit auf Englisch. Die Unterhaltungen behalten ihre Originalsprache bei. Eine zuverlässige semantische Suche auf Deutsch sowie eine sprachübergreifende Suche können derzeit nicht garantiert werden.

Installiere die Erweiterung in Chrome oder Microsoft Edge auf deinem Desktop, importiere deinen unterstützten Verlauf und beginne mit einem markanten Begriff aus einer gespeicherten Unterhaltung.
